Documentation

Base URL

POST {{ api_base_url }}

Toutes les requetes se font en POST, en form-data (ou en parametres d URL), avec au minimum ta cle API et une action.

Parametres communs

ParametreDescription
keyTa cle API (obligatoire sur chaque requete)
actionbalance, services, add, ou status

Solde action=balance

key={{ api_key or 'TA_CLE' }}
action=balance

Reponse :

{ "balance": "12500", "currency": "FCFA" }

Liste des services action=services

key={{ api_key or 'TA_CLE' }}
action=services

Reponse :

[
  {
    "service": 12,
    "name": "Followers TikTok",
    "category": "tiktok",
    "rate": 7.9,
    "min": 100,
    "max": 50000,
    "type": "Default"
  }
]

Passer une commande action=add

ParametreDescription
serviceID du service (voir action=services)
linkLien du compte / de la video
quantityQuantite (non requis si le service est de type "Custom Comments")
commentsUniquement pour les services "Custom Comments" : 1 commentaire par ligne
key={{ api_key or 'TA_CLE' }}
action=add
service=12
link=https://tiktok.com/@moncompte
quantity=1000

Reponse :

{ "order": 4581 }

Statut d une commande action=status

key={{ api_key or 'TA_CLE' }}
action=status
order=4581

Reponse :

{
  "charge": "7900",
  "start_count": "0",
  "status": "en_cours",
  "remains": "300",
  "currency": "FCFA"
}
